# TECHAM Replay per Kodi

Repository ufficiale Kodi per l'add-on **TECHAM Replay Sync**.

## Installazione

1. Scarica `repository.techamreplay-1.0.4.zip` dalla cartella `zips/repository.techamreplay`.
2. In Kodi apri **Add-on → Installa da file ZIP** e seleziona il file scaricato.
3. Apri **Add-on → Installa da repository → TECHAM Replay Repository → Servizi → TECHAM Replay Sync**.

Dopo la prima installazione, Kodi rileverà gli aggiornamenti da questo repository.

## Pannello di stato

Dalla versione 0.3.0 apri **Add-on → Add-on programmi → TECHAM Replay Sync** per:

- controllare collegamento, ultima sincronizzazione e coda offline;
- verificare la connessione al profilo Replay;
- inviare subito gli elementi rimasti in attesa;
- aprire le impostazioni dell'add-on.
